# Git Workflow Rules

- **DILARANG AUTO PUSH**: Jangan pernah menjalankan perintah `git push` secara otomatis.
- Jalankan `git push` HANYA jika diminta atau dikonfirmasi secara eksplisit oleh pengguna.
- Perubahan kode cukup diuji dan/atau dibuatkan commit lokal jika diperlukan, lalu laporkan kepada pengguna bahwa perubahan siap di-push.
